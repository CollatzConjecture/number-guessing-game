# Mobile Number Guesser

Mobile Number Guesser is an engaging and entertaining mobile game developed using React Native. Put your deduction skills to the test as you attempt to guess the mystery mobile number. With its user-friendly interface and addictive gameplay, this game is perfect for players of all ages.

## Features

- **Number Guessing:** Challenge yourself to guess the correct mobile number within a limited number of attempts.
- **Hints & Clues:** Receive hints to guide your guesses based on proximity to the target number.
- **User-Friendly Interface:** Enjoy an intuitive and easy-to-navigate interface.
- **Addictive Gameplay:** Simple yet challenging mechanics that keep players engaged.

## Getting Started

### Prerequisites

Before you begin, ensure you have met the following requirements:

- **Node.js** (v14.x or higher)
- **npm** or **yarn**
- **React Native CLI** or **Expo CLI**
- **Android Studio** (for Android development) or **Xcode** (for iOS development)

### Installation

1. **Clone the repository:**

    ```bash
    git clone https://github.com/CollatzConjecture/number-guessing-game.git
    cd number-guessing-game
    ```

2. **Install the dependencies:**

    If you're using npm:

    ```bash
    npm install
    ```

    Or if you're using yarn:

    ```bash
    yarn install
    ```

### Running the Application

#### Running on Android

1. **Start the Android emulator:**

    ```bash
    npx react-native run-android
    ```

2. **Launch the app:**

    The app should automatically open in your Android emulator.

#### Running on iOS

1. **Start the iOS simulator:**

    ```bash
    npx react-native run-ios
    ```

2. **Launch the app:**

    The app should automatically open in your iOS simulator.

### Usage

- **Start a New Game:** Launch the app and begin guessing the mystery mobile number.
- **Make a Guess:** Input your number guess and receive feedback on how close your guess is.
- **Win the Game:** Keep guessing until you correctly identify the mystery number.
